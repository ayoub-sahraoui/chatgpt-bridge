### Local ChatGPT Bridge Access
You have access to a local ChatGPT REST API running at `http://127.0.0.1:8787`.
You can delegate complex thinking, coding, drafting, or search tasks to ChatGPT by sending standard HTTP requests:

1. **Ask ChatGPT (Single-Turn or Multi-Turn)**:
   curl -s -X POST http://127.0.0.1:8787/ask \
     -H "Content-Type: application/json" \
     -d '{"prompt": "Your question or task here"}'

   • Returns JSON: `{"taskId": "...", "text": "", "elapsedMs": 1234}`
   • By default `newChat: false` continues in the current conversation thread.
   • To start a fresh conversation, pass `{"prompt": "...", "newChat": true}`.

2. **OpenAI SDK / Client Compatibility**:
   Point any OpenAI-compatible client (LangChain, AutoGen, CrewAI, Python `openai` library) to:
   • Base URL: `http://127.0.0.1:8787/v1`
   • API Key: any string (e.g. `sk-local`)
   • Endpoint: `POST /v1/chat/completions`

3. **Management Endpoints**:
   • Reset to new chat: `POST http://127.0.0.1:8787/new-chat`
   • Stop in-flight task: `POST http://127.0.0.1:8787/cancel`
   • Get last reply: `GET http://127.0.0.1:8787/last-response`
   • Health status: `GET http://127.0.0.1:8787/health`

📚 REST Endpoints Reference
POST /ask — Main endpoint to prompt ChatGPT
FieldTypeDefaultDescription
prompt (or message)stringrequiredThe text prompt to type into ChatGPT.
newChatbooleanfalseSet true to start a new chat before sending; false continues in the same thread.
streambooleanfalseSet true to stream deltas via Server-Sent Events (SSE).
cURL EXAMPLE 
curl -X POST http://127.0.0.1:8787/ask \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Explain quantum computing in two sentences",
    "newChat": false
  }'
PYTHON (requests) 
import requests

res = requests.post("http://127.0.0.1:8787/ask", json={
    "prompt": "Explain quantum computing in two sentences",
    "newChat": False
})
print(res.json()["text"])
POST /v1/chat/completions — OpenAI-compatible completions

Compatible with any OpenAI SDK or agentic framework by simply overriding base_url.

PYTHON (openai SDK) 
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8787/v1", api_key="not-needed")

response = client.chat.completions.create(
    model="chatgpt",
    messages=[{"role": "user", "content": "Explain quantum computing in two sentences"}],
    stream=False
)
print(response.choices[0].message.content)
