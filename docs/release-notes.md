## Downloads

- **Production:** download the ZIP ending in `-chrome.zip` for everyday use.
- **Development:** download the ZIP ending in `-chrome-dev.zip` for a development build.

## Install

1. Download and extract the production ZIP.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted directory containing `manifest.json`.
4. Complete the [native-host setup](https://github.com/ayoub-sahraoui/chatgpt-bridge#quick-start), then open ChatGPT in the same browser profile and sign in.

The extension includes a rounded page panel with inline settings, light/dark/system themes, REST API examples, automation controls, and diagnostics. The local bridge supports streamed responses and SDK file attachments.
